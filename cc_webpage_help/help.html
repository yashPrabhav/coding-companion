COMMON QUESTIONS

Frequently asked questions

Quick answers to help you get unstuck.

How should I ask a coding question?

Describe your goal, include the relevant code if possible, and explain what you expected versus what happened.

Can I ask questions about code I already have?

Yes. Share the relevant code using the controls available in your app and explain which part you want to understand.

What if the app is not responding correctly?

Try refreshing the app. If the issue continues, contact support with a description of the problem and the steps that caused it. Avoid including passwords or private keys.
