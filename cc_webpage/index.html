GOOD TO KNOW

Frequently asked questions

A few things to know before you get started.

What is Coding Companion?

Coding Companion is an AI-powered learning product designed to help people understand coding concepts, explore code, and practise problem-solving through conversation.

Who is Coding Companion for?

It is being built for learners who want help understanding code and developing their problem-solving skills. The experience may vary depending on the current product version.

Can I ask questions about code I have written?

Yes. You can share relevant code using the controls available in the app and ask questions about how it works, what it means, or where you are stuck.

Does Coding Companion guarantee correct answers?

No AI system is guaranteed to be correct every time. Review explanations, test code, and verify important information rather than relying on an answer blindly.
